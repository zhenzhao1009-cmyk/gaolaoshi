# 五朵花模型视觉优化报告

## 优化时间
2025年（当前会话）

## 优化目标
提升 3D 花卉模型的视觉真实度，专注于：
- 物理材质光学特性
- 花蕊植物学准确性
- 花瓣叶脉纹理细节
- 叶片边缘形态

## 实施内容

### 1. 花卉专属材质系统（`material` 函数重构）

#### **荷花 (Lotus) - 蜡质光泽**
```javascript
roughness: 0.48  // 降低粗糙度
sheen: 0.82      // 强光泽（蜡质反射）
clearcoat: 0.15  // 蜡质涂层效果
sheenColor: '#fce8eb'  // 粉白光晕
```
**视觉效果**：模拟荷花"出淤泥而不染"的防水蜡质表面，高光更聚焦。

#### **百合 (Lily) - 丝绸光泽 + 半透**
```javascript
roughness: 0.42
sheen: 0.92      // 最强丝绸光泽
sheenColor: '#fdfaef'  // 奶白色光晕
clearcoat: 0.08  // 微弱涂层
```
**视觉效果**：高贵的丝绸质感，边缘轻微透光。

#### **玫瑰 (Rose) - 天鹅绒质感**
```javascript
roughness: 0.72  // 最高粗糙度
sheen: 0.65      // 中等柔和光泽
sheenColor: '#d8344c'  // 深红光晕
clearcoat: 0.02  // 几乎无涂层（哑光）
```
**视觉效果**：绒布般的漫反射，深沉内敛的红色。

#### **山茶 (Camellia) - 柔和光泽**
```javascript
roughness: 0.58
sheen: 0.78
clearcoat: 0.12
sheenColor: '#f9ebe8'  // 暖白光晕
```
**视觉效果**：介于荷花和玫瑰之间的半光泽感。

#### **樱花 (Cherry Blossom) - 纸质薄透**
```javascript
roughness: 0.38
sheen: 0.88
transmission: 0.06    // 新增透射光
thickness: 0.5        // 薄花瓣
sheenColor: '#fdeef3'
```
**视觉效果**：宣纸般的轻盈感，背光时可见透射光晕。

### 3. 花瓣叶脉纹理系统（`buildPetalGeometry` 函数）

#### **叶脉颜色加深**
```javascript
// 主叶脉（中心线）
const veinDarken = 0.018 * Math.exp(-x*x*18) * Math.sin(Math.PI*t);

// 侧脉纹理
const lateralVeins = 0.012 * Math.abs(x) * Math.cos(x*9*Math.PI+t*2) * smooth(t);
```
**效果**：中央主脉明显，侧脉从主脉向边缘分叉，自然衰减。

#### **叶脉凸起（几何浮雕）**
```javascript
// 主脉凸起：高斯分布
const mainVein = 0.0025 * Math.exp(-x*x*24) * Math.sin(Math.PI*t*0.8);

// 侧脉凸起：正弦波
const sideVein = 0.0018 * Math.cos(x*9*Math.PI+t*2) * Math.sin(Math.PI*t);

const veinRelief = mainVein + sideVein;
```
**效果**：花瓣表面不再完全光滑，主脉和侧脉有微小凸起，增强立体感。

### 4. 叶片边缘锯齿（`leaf` 函数）

#### **实现方式**
新增 `serrated` 参数，在叶片边缘添加正弦波扰动：
```javascript
if(serrated){
  const theta = Math.atan2(z, x);
  const sawTooth = 0.003 * Math.sin(theta * 28);  // 28个锯齿
  // 仅对边缘顶点（radialDist > 0.08）应用
}
```

#### **应用范围**
- **玫瑰叶片**：启用锯齿（真实玫瑰叶有锯齿边缘）
- **山茶叶片**：启用小锯齿（山茶叶也有细齿）
- **百合叶片**：保持光滑（百合叶无锯齿）
