# 写实花卉素材

本目录包含荷花、百合、玫瑰、山茶、樱花五套透明阶段图。每张 PNG 为 1536×1024，按 3 列、2 行保存六个从花苞到盛放的状态，单格 512×512。

生成方式：内置 Image Gen，透明背景；完整提示词见 prompts.json。素材属于 AI 辅助创作，参赛时请与自有交互设计、实现和人工迭代分别说明。

页面通过 Canvas 裁取阶段格，在手势对应的开度之间进行透明混合；这是六阶段图像过渡，不是拍摄的连续开花视频。图像只能进行轻微二维倾斜，不能表现真实的三维转身。

素材按需加载并计入已有缓存预算。默认优先使用本目录的写实素材；加载失败时尝试原有颜色/遮罩序列，再回退到程序立体花。

本轮验证：五张素材均有有效 alpha 透明通道，六格尺寸一致；24 项模拟逻辑检查通过。真实浏览器画面和摄像头仍受本机自动化权限限制，未完成实机验证。
