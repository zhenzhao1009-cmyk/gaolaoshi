# 快速视觉检查清单

## 启动方式
1. Windows：双击 `START-Windows.bat`
2. Mac：双击 `START-Mac.command`
3. 浏览器访问：http://localhost:8765/

## 优化验证步骤（约 3 分钟）

### 1. 荷花 (Lotus) 检查
- [ ] **材质光泽**：花瓣有明显蜡质光泽（高光聚焦，不漫散）
- [ ] **莲蓬种子**：中心莲蓬有密集的 120 颗种子（螺旋排列）
- [ ] **雄蕊数量**：花蕊周围有大量金黄色雄蕊（120 根）
- [ ] **颜色渐变**：花瓣从根部粉白渐变到尖端深粉，主脉颜色略深

**快速验证**：按 `↑` 键调整到 80% 开度，观察莲蓬和雄蕊是否清晰可见。

---

### 2. 百合 (Lily) 检查
- [ ] **丝绸质感**：花瓣有高级丝绸光泽（不是塑料光泽）
- [ ] **T字花药**：6 根雄蕊顶端有明显的橙棕色 T 字型花药
- [ ] **雌蕊柱头**：中心有一根雌蕊，顶端绿色柱头明显
- [ ] **叶片光滑**：茎下方 4 片叶子边缘光滑无锯齿

**快速验证**：按 `5` 键完全盛放，观察花药是否比之前更大更明显。

---

### 3. 玫瑰 (Rose) 检查
- [ ] **天鹅绒质感**：花瓣深红色且哑光（不反光，像绒布）
- [ ] **叶片锯齿**：茎下方 2 片叶子边缘有明显的锯齿（约 28 齿）
- [ ] **层层包裹**：6 层花瓣紧密包裹，最外层是绿色萼片
- [ ] **叶脉纹理**：花瓣上可见主脉和侧脉（颜色略深）

**快速验证**：按 `3` 键半开状态，观察叶片锯齿和天鹅绒质感。

---

### 4. 山茶 (Camellia) 检查
- [ ] **柔和光泽**：花瓣有中等光泽（介于荷花和玫瑰之间）
- [ ] **叶片锯齿**：茎下方 2 片叶子有小锯齿（比玫瑰细）
- [ ] **雄蕊数量**：中心有 35 根黄色雄蕊，呈放射状
- [ ] **花瓣颜色**：白色带淡粉，从内到外渐变

**快速验证**：按 `4` 键接近盛放，观察叶片和雄蕊细节。

---

### 5. 樱花 (Cherry Blossom) 检查
- [ ] **纸质薄透**：花瓣有宣纸般的轻盈感（最薄的花瓣）
- [ ] **透射光效果**：逆光或强光下花瓣边缘有微弱透射光晕
- [ ] **三分支结构**：3 个分支，每个分支有一簇花朵
- [ ] **雄蕊数量**：每朵花中心约 30 根雄蕊（比之前更多）
- [ ] **花瓣缺口**：5 瓣花瓣顶端有心形缺口

**快速验证**：按 `5` 键完全盛放，观察透射光和缺口细节。

---

## 全花种通用检查

### 叶脉纹理系统
- [ ] **主叶脉**：每片花瓣中央有一条明显的主脉（颜色略深）
- [ ] **侧叶脉**：从主脉向两侧有 9 条分叉侧脉
- [ ] **几何凸起**：近距离观察时主脉和侧脉有微小凸起（不是完全平面）

**验证方式**：鼠标拖动花朵画布，旋转到侧面 45° 角度，观察花瓣表面起伏。

### 材质对比
按 `← →` 键快速切换不同花种，对比材质差异：
- 荷花：**最亮**（蜡质高光）
- 百合：**次亮**（丝绸光泽）
- 山茶：**中等**（半光泽）
- 玫瑰：**最暗**（天鹅绒哑光）
- 樱花：**最薄**（纸质透光）

### 性能检查
- [ ] **帧率稳定**：所有花种在 1440p 分辨率下保持 60fps
- [ ] **无卡顿**：切换花种时无明显卡顿或延迟
- [ ] **内存正常**：双花模式（按 `D` 键）下内存占用 < 300MB

## 常见问题排查

### Q1: 看不到莲蓬种子密集排列
**原因**：开度不够，种子被花瓣遮挡  
**解决**：按 `5` 键完全盛放，或按 `↑` 键调整到 80% 以上开度

### Q2: 百合花药不明显
**原因**：观看角度或光照问题  
**解决**：鼠标拖动旋转到正面或侧面 30° 角度，花药应该比之前大 40%

### Q3: 叶片锯齿不清晰
**原因**：分辨率过低或距离过远  
**解决**：放大浏览器窗口到全屏，或按 `V` 键切换竖屏模式

### Q4: 材质看起来都一样
**原因**：显示器色彩范围有限或光照不足  
**解决**：
1. 检查浏览器硬件加速是否开启
2. 对比最极端的两种：荷花（最亮）vs 玫瑰（最暗）
3. 旋转花朵观察高光反射变化

### Q5: 樱花透射光看不见
**原因**：透射效果微弱（transmission: 0.06），需要特定光照条件  
**解决**：这是正常的，樱花透射光是最细微的优化，主要体现在边缘光晕
