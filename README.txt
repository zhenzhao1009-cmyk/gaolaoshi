启动
--------------------------------------------------
Windows：双击 START-Windows.bat。
Mac：双击 START-Mac.command。
浏览器打开 http://localhost:8765/ 后，点击“开启摄像头”并允许权限。
推荐 Chrome 或 Edge；不要直接双击 index.html。
手机请通过 HTTPS 在线地址访问：iPhone 用 Safari、安卓用 Chrome，并允许网站和系统摄像头权限。局域网 HTTP 地址无法使用手机摄像头。
关闭启动窗口将停止本地服务。模型与识别库在本地，界面不需要联网字体。

可见控制
--------------------------------------------------
自动演示：花朵自动开合，每 10 秒换花；再次点击停止。
双花：显示左右两朵花；真实双手入镜时也会自动进入双花。
竖屏：切换 9:16 录制构图，可用 ?phone 直接进入。
纯净画面：隐藏导航与手势面板，保留退出按钮。
重置：退出演示，恢复初始花种和开度。
操作指引：查看三步入门。
手动赏花：拖动滑杆控制左侧花；操作后短暂优先于摄像头手势。
减少动效：关闭花瓣飘落与背景粒子，减轻持续运动。
关闭摄像头：释放设备；启动失败后可以点击重试。
摄像头预览：以右侧悬浮小窗完整显示；拖动标题栏可移动，双击标题栏或点击“归位”恢复默认位置，“收起控制”只保留画面。移动端首次默认收起；窗口会记住位置、大小和收起状态，并在缩放或旋转屏幕后自动回到可视区域。拖动窗口左下角手柄可调整宽高（240×200 至屏幕大小）。标题栏可直接取消启动或关闭摄像头。

手势
--------------------------------------------------
全花种两指捏合：其余三指收起，拇指与食指张开 / 捏合，连续控制开合。
全花种数指：伸出 0–5 根手指，对应六个阶段；数 2 用食指+中指，拇指+食指为捏合。
展掌：五指展开，花朵完全盛放；张得越开飘瓣越明显，倾斜手掌调整角度。
全花种并指：五指伸直并拢，拇指贴近食指，稳定保持后旋转撒花。荷花、百合、玫瑰的花瓣围着花心顺时针转动，百合叶片与花瓣同向转动，叶根保持与花茎相连，花茎保持稳定；樱花、山茶保持现有旋转效果。松开或移出镜头后停止。左右手均可触发，双花时分别生效。“减少动效”开启时只盛放，不旋转撒花。
横向快挥：右挥下一朵、左挥上一朵。
双手：首次按画面位置绑定左右花，持续追踪期间结合位置和左右手标签保持分配；先举一只手、再补另一只时，会在双手首次同框时按画面左右重新绑定。
单手：左手、右手均可控制当前单枝花；双手回到单手后，剩下的手会在短暂缓冲后接管当前花。
双花仅在两只手同时被识别到时进入；任一只手离开画面即自动回到单花；点击“双花”或按 D 可手动强制开启。
尽量让双手保持可见；完全遮挡或模型分类错误仍可能重新绑定。
离手：保留当前开度，停止手势触发的飘瓣与旋转。

键盘
--------------------------------------------------
空格    开始 / 停止演示
← →     换花；也可点击顶部花名，Shift 点击切换右侧花
↑ ↓     调整开度
0–5     设置开花级别（所有花种均可）
P       开启 / 关闭盛放飘瓣
D       双花
V       竖屏
H       纯净画面
鼠标拖动花朵画布  调整角度

花卉素材
--------------------------------------------------
当前 frames/ 没有工笔素材，页面显示程序实时绘制的立体花。
生成素材的方法见 prompts/flower-video-prompts.txt 和原版教程。
每帧需配对的 0001.jpg（颜色）和 0001.png（透明遮罩）。
在 FLOWERS 配置中填写目录和原始帧数。
页面只按需加载可见花种，缩小解码帧并限制缓存；缺失素材时继续显示立体花。
导入新素材后刷新页面。

验证
--------------------------------------------------
安装了 Node.js 的电脑，在项目目录运行：
  node tools/test_interactions.cjs
  node tools/test_rendering.mjs
  node tools/test_models.mjs
覆盖 41 项模拟交互检查、12 项渲染资源检查和 26 项模型/导出/工作线程检查，包括左右手接管、并指旋转撒花、百合叶片跟随、摄像头恢复和资源释放。
真实摄像头、浏览器布局及设备性能仍需实机验证。

视觉优化对比：用浏览器打开 tools/visual_comparison.html 查看五朵花模型优化前后的详细对比。

3.0 更新（2026-11-04）
--------------------------------------------------
本版主页使用本地程序绘制花朵，并保留此前的 Three.js 实验模块。

- 五种花新增五指并拢旋转撒花，松开或离开镜头后停止。
- 荷花增加两支独立荷叶、深蓝椭圆水面、三支茎柄的入水渐隐与涟漪。
- 百合叶片跟随花瓣转动，叶根保持连接；删除最靠近花朵的叶片。
- 玫瑰增加六枚错落弯刺；山茶与樱花保留最初的旋转撒花效果。
- 改善手机摄像头启动与高分屏清晰度，单手支持左右手接管当前花。
- 保留并修正实验模块的渲染目标、材质纹理与资源释放逻辑。

完整更新见 CHANGELOG.md；历史实验设计记录见 design/ 下的说明文档。
历史性能数字不代表本版实机测量结果。
